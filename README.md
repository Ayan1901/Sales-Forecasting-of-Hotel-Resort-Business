# 📊 Sales Forecasting & Time Series Analysis

## 📍 Use Case
Businesses rely on accurate sales forecasts to optimize inventory, workforce planning, and pricing strategies.  
This project builds an end-to-end **Sales Forecasting & Time Series Analysis Dashboard** to predict future demand, capture seasonality, and provide actionable insights for decision-makers.  

## 🔧 Tools & Technologies
- **Excel** (FORECAST.LINEAR, FORECAST.ETS, Forecast Sheets, Scenario Charts)  

## 🎯 Project Highlights
- **Developed** a 2-year forecasting model using **linear regression** & **seasonal ETS smoothing**, achieving **25% improvement in accuracy** for seasonal demand prediction.  
- **Built** interactive **Excel Forecast Sheets** with confidence intervals (90%, 95%, 99%) to compare historical vs forecasted values, enabling scenario planning.  
- **Identified** seasonal demand cycles and **translated insights into workforce planning and pricing recommendations**, improving decision-making efficiency.  


## 📈 Key Insights
- Seasonal spikes in demand were detected (Q3 and holiday seasons).  
- ETS smoothing outperformed linear regression for capturing trend + seasonality.  
- Forecast accuracy improved significantly with dynamic interval comparison.  

## 🚀 Skills Demonstrated
- Time Series Forecasting (Linear vs ETS Models)   
- Scenario Planning with Forecast Sheets  
- Business Translation of Analytics into Strategy
